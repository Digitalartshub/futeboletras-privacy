## Publicar no GitHub Pages

1. Criar um repositorio publico no GitHub, por exemplo `futeboletras-privacy`.
2. Fazer upload destes ficheiros para o repositorio:
   - `index.html`
   - `privacy-policy.md`
   - `README.md`
3. Abrir `Settings`.
4. Ir a `Pages`.
5. Em `Build and deployment`, escolher `Deploy from a branch`.
6. Escolher `main` e `/root`.
7. Guardar.

O link final deve ficar parecido com:

`https://TEU-USERNAME.github.io/futeboletras-privacy/`

Esse e o link que deves colocar no AdMob e na Play Console como URL da politica de privacidade.
